# 天地图真实 Key 浏览器验收

## Goal

使用已配置的 VITE_TIANDITU_KEY 验证天地图组件真实 SDK 加载与基础交互

## 范围

- 打开 `/tests/tianditu-map.html`。
- 检查 SDK 加载、单点聚焦、地图容器和缩放按钮。
- 若发现实现问题，修复后重新运行类型检查、构建和浏览器验证。

## 验收标准

- 回归页加载真实天地图底图，不显示缺少 Key 或加载失败提示。
- 页面显示“PASS 天地图真实 SDK 已初始化”。
- 测试点标记可见，点击后能打开名称、备注和外链弹窗。
- 地图容器、放大和缩小按钮可用。
- `npm run lint`、`npm run typecheck`、`npm run build` 通过。

## 限制

- 不更改高德组件和其他旅行页面。
- 不把真实 Key 写入仓库或任务文档。
