# ReUI 多类型表格与拖拽排序

## 目标
将现有通用记录表升级为 ReUI Data Grid，方便记录住宿、预订及其他结构化数据；保持现有页面风格和云端同步方式。

## 已确认背景
- 用户已选 ReUI，批准任务与实施，并强调代码/组件拆分及跨页面复用。
- 现有入口为通用表格页及北海道住宿区，资源 ID 保持不变。
- `src/components/editable-table.tsx` 提供受控表格；当前 schemaVersion=1，所有单元格为字符串。
- `src/components/synced-table.tsx` 负责权限与同步；D1 保存任意 JSON 文档，无需增加数据库或 SQL 表。
- 表格数据只存线上 D1，开发页也连接生产接口。浏览器只记密码，未保存编辑仅在页面内存。

## 需求
- R1：采用 ReUI 免费 Data Grid，沿用项目主题，两个入口共用组件。
- R2：行号旁提供拖拽手柄，拖动整行排序，内容和稳定 ID 不变；保留上下移动按钮作为键盘/触摸辅助。拖拽期间不能被轮询刷新打断。
- R3：支持文本、多行文本、数字、金额、日期、单选、多选、勾选、网址。字段类型是列级配置，表头可改名；新增字段时选择类型，选择类字段可设置选项。
- R4：支持新增行和字段。已有字段可调整配置；有内容时转换必须无损，不能转换则提示对应行并保持原数据。删除仍被引用的选项必须阻止，不能静默清空单元格。
- R5：保留双击编辑、多行 Enter 换行、Ctrl/⌘+Enter 或失焦保存、Esc 取消及自动行高。日期/选择弹层内部切换焦点不能提前提交。
- R6：公开只读，共享密码解锁；只读不可改值、字段或顺序。复用原有节流、轮询、离线重试和版本冲突提示。
- R7：旧数据完整加载，包含换行、空值、列顺序和行顺序；打开旧表不会触发写入，首次实际修改才升级保存。旧版本客户端遇到新结构应拒绝覆盖。
- R8：保留 50 列、1000 行、512 KiB 限制；错误可读，非法输入不覆盖最后有效值。

## 字段行为
- 文本/多行：字符串；已有列按多行文本兼容，不能凭列名猜测并转换旧值。
- 数字：有限数字，可空；非法输入提示，不把空值当零。
- 金额：数字，展示两位小数；不做汇率换算、不强制货币符号。
- 日期：本地日历日期，可空，不因时区偏移一天。
- 单选/多选：列配置的选项；多选显示标签。
- 勾选：布尔，新增默认未勾选；空值与 false 的转换仅按明确规则处理。
- 网址：可空，只接受 http/https；显示可访问链接，编辑与打开链接分离。

## 验收
- A1/R1,R2：两入口能拖动首/中/末行，取消拖拽不改数据；首尾辅助按钮禁用；移动后另一页面按新顺序显示。
- A2/R3,R4：九类字段可新增、编辑、保存、刷新回读；单选/多选选项配置生效。非法转换与已用选项删除不会损失数据。
- A3/R5：多行输入自动增减行高，键盘确认/取消及中文输入法正常，弹层点击不丢编辑。
- A4/R6：未解锁只读；不同页面同时编辑保留冲突处理；失败不能误报已保存。
- A5/R7：v1 文档加载不写；首次修改保存 v2，原单元格与 ID 保留；新数据类型由 JSON 原生类型表达。
- A6/R8：边界与非法输入测试通过；桌面/窄屏可横向滚动，操作不被遮挡。

## 范围外
附件上传、公式计算、关联记录、透视分析、看板/日历视图、多人光标和权限体系升级；这轮也不加排序/筛选视图以免与手动行顺序冲突。
