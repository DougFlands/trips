# 通用表格支持链接密码解锁

- `SyncedTable` 自行读取地址栏的 `pwd`，与手动输入共用现有密码校验。所有表格都支持这两种入口，页面无需传递密码。
- `pwd` 有值时自动尝试解锁。输错或校验请求失败时保持锁定，不显示错误，仍可手动输入。手动提交沿用现有错误提示。
- 没有 `pwd` 或值为空时，沿用浏览器已记住密码的解锁流程。
- 通用布尔参数 `hideWhenLocked` 默认为 `false`，锁定时可只读查看。北海道页面传入 `hideWhenLocked`，锁定时只显示解锁入口，校验成功后展示表格。
- 主动锁定后立即回到对应的锁定视图。本次挂载只自动尝试一次链接密码。
- 业务代码只改两处：`SyncedTable` 负责展示和解锁交互，北海道页面在现有调用处增加一个布尔属性。
