# 通用表格工具与 Cloudflare 自动同步

## Goal

在旅行站内提供一个可复用的轻量表格工具，用于记录住宿、费用、备忘等小量数据。表格组件与数据同步能力分开，后续非表格数据也能复用存储和同步逻辑。

## Requirements

- R1：复用项目现有视觉风格和开源组件；提供双击单元格编辑、添加行、添加列、修改表头。
- R2：表格为受控组件，只接收数据、只读状态和变更回调，不绑定旅行页面、密码或 Cloudflare。
- R3：通用同步 hook 接受可序列化数据与资源标识；修改后节流保存，同时自动读取远端更新。
- R4：保存中、已同步、未保存、失败、冲突状态可见；网络失败或远端更新不得静默丢弃本地修改。
- R5：未验证时只能查看；固定共享密码核对成功后可编辑，本地保存密码或可核对状态，下次进入可恢复有效权限。无需账号体系。
- R6：实施顺序为表格组件、通用同步方法与本地验证，然后接入 Cloudflare。用户已提供登录中的 Edge Cloudflare 账号，后续接入可使用。
- R7：小量数据优先，避免增加全局状态库、完整电子表格引擎或复杂实时协作设施。

## Background

- `src/App.tsx` 使用 pathname 和普通链接；项目为 React 19、Vite、TypeScript，部署到 Cloudflare Pages。
- `src/components/ui/table.tsx`、`input.tsx`、`button.tsx` 等已存在；全局语义主题在 `src/styles.css`。
- `components.json` 已配置 ReUI registry，目前只有 timeline；没有已安装的表格引擎。
- `functions/_AMapService/[[path]].js` 是现有 Pages Function；未发现 D1 绑定、迁移或通用同步 API。
- 用户要求后续复用其他类型的数据存储，故同步能力不能依赖表头、行列或民宿字段。

## Acceptance Criteria

- [x] AC1 / R1、R2：桌面双击单元格或表头进入编辑，Enter/失焦提交，Escape 取消；中文输入法组合输入不被 Enter 提前提交。键盘和触屏有可用的编辑入口。
- [x] AC2 / R1、R2：新增行、列后可立即编辑；列具有稳定 ID，改表头不丢失已有单元格内容；只读模式下所有修改入口失效。
- [x] AC3 / R3：连续修改按配置间隔合并保存，尾部修改必定提交；写入期间产生的新修改不被较旧响应覆盖。
- [x] AC4 / R3、R4：两个页面可自动看到对方已保存内容；读取响应乱序、正在编辑、资源切换时不会串写或覆盖草稿。
- [x] AC5 / R4：离线、服务端失败与版本冲突均有明确状态；草稿保留，恢复网络可重试；并发修改不会静默互相覆盖。
- [x] AC6 / R5：密码错误不能编辑；正确后可编辑；刷新可验证本地保存的状态；失效状态回到只读；可主动锁定并清除本地凭据。
- [x] AC7 / R2、R3：一个非表格 JSON 示例可复用同一同步 hook，无需导入表格组件或数据类型。
- [x] AC8 / R6：组件与 hook 可通过本地可控服务验证；真实 Cloudflare 同步须另以 D1 绑定后的两页面读写验收，不能把本地模拟称为已上线。
- [x] AC9 / R1：沿用语义主题和已有控件；窄屏表格区域横向滚动，工具栏、密码输入和同步状态可操作；原有旅行路由正常。

## Out of scope

- 公式、跨单元格计算、合并单元格、拖拽排序、批量粘贴、Excel 导入导出、附件上传。
- 完整账号、成员角色、权限管理、多人光标、WebSocket/CRDT 实时协作。
- 自动表单设计器、复杂数据库查询平台和大规模虚拟滚动。
- 本轮先完成组件和同步方法；不因已提供登录状态而提前修改 Cloudflare 线上配置。
