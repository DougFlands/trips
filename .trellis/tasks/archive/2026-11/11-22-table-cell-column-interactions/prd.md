# 表格选择编辑与列布局交互

用户已审阅方案并明确要求开发全部功能（2026-11-22）。

- 单击单元格高亮；选中后直接打字替换值，双击/Enter/F2编辑原值；支持中文输入法。
- 单元格无保存/取消按钮；失焦/单行Enter/Tab提交，Esc取消；多行Enter换行、Ctrl/Cmd+Enter提交。非法值保留草稿并提示。
- 表头边界调整列宽，列手柄横向调整顺序；保留现有行拖拽，行号列不可拖动/缩放。
- 列设置按钮下方Popover展示原字段表单，保存成功关闭，Esc/外部点击取消；新增字段也复用弹层。
- 列宽/顺序云端保存，拖动结束才提交；旧数据默认宽度，权限/冲突/同步行为不变。
- 组件保持跨页面复用；无本地数据持久化。

验收：类型/布局纯函数测试，完整check/test；浏览器验证九类型、焦点与输入、无按钮、行列拖拽不冲突、列宽、Popover与只读；不改真实住宿数据。
