# 技术方案

## 页面与复用

- 新 feature 放 src/trips/guangdong-stargazing/，维护 page.tsx、places.ts、weather.ts、styles.css；按实际体量拆分，不新增状态库或路由库。
- 观星目录没有逐日行程。在 App.tsx 增加精确路径分支与首页入口，使用本页元信息；不为适配 Trip 制造空日程、餐饮和酒店。
- 复用 TravelMap.tsx 的 Loader、安全配置和生命周期。只为真实共享需求补充普通点位模式、选中回调、弹窗元信息、区域外链和主题类；旧 props/default 保持兼容。
- 普通地图地点只要求真实必需字段；不能给观星点填虚构 score。排序/天气变化不能重建底图实例。普通点位不连路线。
- AMap 无类型边界留在共享地图文件。新主题与 marker/popup CSS 按本页类限定，检查现有青岛全局 .map-* 选择器及高德弹窗挂载容器，避免样式冲突。

## 数据流程

Edge 搜索 → 同词记录 → 全局去重 → 候选详情核验 → 地点/坐标/开放信息 → 天空亮度等级 → 静态点位目录 → 搜索排序 → 列表/地图。

页面启动 → IndexedDB 缓存 → 夜晚选择。
更新按钮 → Open-Meteo → 响应校验 → 页面状态与 IndexedDB。

## 地点与坐标

- 稳定 ID、名称、城市、描述、地点精度、来源索引和 WGS84 [lng,lat] 坐标为核心字段。
- 高德 marker/navigation 使用 GCJ-02。使用经过验证的转换函数或权威双坐标来源，保留坐标系；不能将 GCJ-02 直接输入天气接口。
- 山脉/景区范围记录 area 精度并标注参考位置；只有核准具体公开机位才能标精确入口。不能按地图中心猜坐标。
- 当前目录 35 点，含首版 8 点与新增 27 点。每个新增点的主帖详情均已审计；同名地与行政区按证据核准，猴岩只标新丰县，缺牙山来源沿用原帖“禅子顶”拼写。
- 距离用 WGS84 Haversine 与固定深圳市民中心参考点；起点坐标在地点核验时确认。内部不取整，展示 km，清楚标明直线距离。
- 仅保存研究必需的公开帖子元数据、摘要及链接，不存登录状态与网页安全令牌。

## 暗空来源

采用来源：https://www.lightpollutionmap.info/ ，统一查询 **Sky Brightness 2025**。2026-09-08 为核验日期，不是模型年份。35 点均已核对模型弹窗坐标与数值。

- 使用公开页面给出的 Bortle/SQM，记录请求坐标、弹窗采样坐标、图层、模型年份、等级、SQM、链接和核验时间。切点前关闭旧弹窗，核对新弹窗坐标，避免自动平移后采到相邻位置。
- World Atlas 2015 可作为历史估算基线，但必须显示 2015；不可将采集日期 2026 当模型年份。
- VIIRS 辐亮度不能直接当作 Bortle。不按瓦片颜色自创换算，不臆造免费 API 或批量接口。
- 产品保存 {min,max,sqm,year,sampledWgs84} 或 null，完整来源记录保留在研究文件中；单值 min=max，区间按 max 保守排序并显示原区间；未知等级始终末尾。
- 运行时用核验后的静态数据，不需要光污染密钥或轮询。模型值标“光污染估算”，与当晚天气分开。
- 无法核实的模型值保留 null 并报告缺口，不能用帖子口述等级或无来源值补足覆盖率。

## 天气请求

来源：https://open-meteo.com/en/docs 。两点公开示例请求已实测 HTTP 200、CORS *，各返回 168 小时，详见 research/feasibility.md。

- 原生 fetch，输入 WGS84；timezone=Asia/Shanghai、timeformat=unixtime、forecast_days=8，覆盖七个完整跨日夜晚。Unix/8 天组合已实测单点和多点各返回 192 小时。
- hourly 字段：temperature_2m、relative_humidity_2m、precipitation_probability、cloud_cover、cloud_cover_low、cloud_cover_mid、cloud_cover_high、wind_speed_10m、visibility。
- 单位：°C、%、km/h，能见度 m 转 km；null 保持缺测，不能变成 0。
- 全部更新从完整目录出发，最多每批 10 个点，逐批执行。按返回 location ID/请求顺序可靠映射。模式网格坐标不可覆盖拍摄地点坐标。
- 单点共用请求/校验路径；更新过程中禁用重叠天气请求动作，避免单点/批量写入竞争。显示成功/失败进度，请求超时与卸载取消，不无界重试。
- 外部响应从 unknown 校验：位置条数/映射、小时数组等长、时间有序、值是合法范围有限数或 null。无效条目单独失败。
- 请求失败/取消不改旧成功缓存；网络成功但写入失败时可显示本次天气，提示未保存。
- 存储失败按 placeId 放入未保存集合；后续成功批次只移除其实际写入成功的地点。集合清空后才移除全局提示，避免 35 点分批更新时掩盖前批错误。
- 提供天气来源署名；开发时核对当前免费端点用途与配额规则，不开通付费订阅。

## IndexedDB 与时间

- 原生数据库 travel-guides-stargazing，version 1；weather store，keyPath=placeId。
- 保存 schema/provider 版本、请求的 WGS84 坐标、fetchedAt、预报范围、小时数组与单位。fetchedAt 是获取时间，不能叫模型更新时间。
- 读取校验版本/结构/坐标；不匹配记录不能当当前点天气。写入成功以 transaction complete 为准，处理 error/abort/blocked/versionchange。
- 启动只读取缓存，超 6 小时提示旧缓存；预报范围外显示暂无数据。存储故障允许内存显示并提示。
- 使用 Unix 时间与 Asia/Shanghai 展示/分组；夜晚窗口 [18:00, 次日06:00)，缺失时段不填 0。今晚已过去时段与未来预报区分。
- 不做服务端同步；用户清理浏览器站点数据会清除天气缓存。

## 页面构成与样式

顶部：返回首页、标题、点位数、资料核验日期、更新全部天气。
控制区：地点搜索、距离/等级与升降序、夜晚选择。
列表：名称/城市、距离、Bortle 估算、云量/降水概览、获取时间、单点更新。
地图/详情：双向选中、拍摄理由/视野、通达/夜间限制、逐小时天气、来源与导航。

采用 README.md 风格库中的 Sketchbook：米白、墨绿、手绘细线、便签卡；地图原色，不加滤镜/纸纹。用现有 shadcn Button/Card/Badge/Alert 等，按页面根容器覆盖 tokens。缓存缺失不阻止地点阅读，地图失败仍能用列表。

## UI组件与动画复查

基础控件统一复用项目shadcn源码，日期使用ToggleGroup，来源用Accordion，表格用Table，列表用ScrollArea与Card子组件。新增lucide-react图标，与components.json配置一致。动画使用本页CSS，涵盖列表/详情/日期切换、卡片反馈、折叠高度、天气Spinner与Progress，支持减少动态效果；不引入动画运行库。保留紧凑布局与完整摘要。

排序控件最终使用shadcn Radix Select；原生select在内置预览无法弹出菜单。选项以portal渲染，附带本页主题，明确验证用户点击路径。

地点详情按用户最新要求去掉位置精度展示；坐标/精度仍保留在数据及地图参考说明中。直接展示波尔特等级、模型年份及图层链接，移除SQM与光污染标签。天气直接展示表格，日期仍由顶部日期控件决定，表格无障碍标题保留地点与日期。

列表卡片顶部左侧为地点名，右侧为距离及波尔特级别；城市/区县与地形紧随其后。继续压缩卡片内外间距，摘要使用12px字号、18px行高，完整换行。
