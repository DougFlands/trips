# 接入 OpenFreeMap 地图组件并移除天地图

## Goal

新增可复用的 OpenFreeMap 地图组件，供旅行页面展示地点标记与详情；移除现有天地图接入。

## Background

- 项目为 React 19、TypeScript、Vite 8 静态站点。
- `src/TiandituMap.tsx:82` 导出独立天地图组件；当前仅 `tests/tianditu-map.html:10` 引用，无业务页面调用。
- `src/map/types.ts:5` 提供地点数据形状；旧行程和观星页面向高德传入 GCJ-02 坐标，不能直接解释为 WGS84。
- `.env.example:3` 和 `README.md:30` 包含天地图配置说明；架构规范有对应契约。
- 工作区已有北海道页面、入口和架构文档的未提交修改，实施时须保留。

## Requirements

- R1：新增独立地图组件，使用 OpenFreeMap 底图与 MapLibre GL JS，无需 Key。
- R2：接收 WGS84 地点数组，展示可自定义文字、颜色的标记；点击或键盘操作可查看名称、说明及可选外链。
- R3：支持父组件指定当前地点、标记选择回调、多点全图和单点聚焦。数据更新不得残留旧标记或错开弹窗。
- R4：支持缩放、浏览器定位、响应式容器；保留地图署名。加载中和失败时提供明确提示，地点信息仍可访问。
- R5：删除天地图组件、专用测试和环境变量配置，更新 README 与当前架构规范。历史任务、日志作为历史记录保留。
- R6：提供可打开的演示/回归页，验证真实底图和标记。

## Acceptance Criteria

- [x] AC1 / R1：未配置地图 Key 时，演示页可加载 OpenFreeMap 真实底图。
- [x] AC2 / R2：多个地点标记与输入坐标一致；鼠标和键盘均可打开对应详情，自定义标记文字/颜色有效。
- [x] AC3 / R3：首次选点、跨地点切换、重复点击、全图后选点、空数组和单点均无旧视图覆盖；筛选移除的点和弹窗消失。
- [x] AC4 / R4：桌面与窄屏地图、控件、弹窗及署名可用；网络失败有提示；卸载/重挂无重复实例或资源残留。
- [x] AC5 / R5：运行代码、当前配置和使用文档无天地图 SDK、组件或 Key 引用；旧业务页面仍可构建。
- [x] AC6 / R6：演示/回归页通过，lint、typecheck、build 通过，npm audit 结果已核查。

## Out of Scope

- 高德地图移除或业务页面地图迁移。
- 北海道景点坐标采集和页面接入；已有相关任务单独处理。
- 地点搜索、导航路线计算、编辑/保存标记、聚合、后端及发布。
- 旧行程模式的逐日连线；本次新组件以地点标记模式交付。
