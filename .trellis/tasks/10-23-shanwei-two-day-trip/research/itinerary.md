# 汕尾两天一夜本地行程

时间边界：第一天中午到达；第二天下午 16:00 离开。只写汕尾当地顺序，不绑定汕尾站、住宿区或返程站。

## D1｜城区吃逛线

1. **12:00—13:30 城区午餐**：品清湖或城区先吃牛腩、牛肉粿条、肠粉。排队超过 30 分钟切 Plan B。
2. **13:40—15:20 凤山祖庙 / 凤仪台**：妈祖石像、天后阁与品清湖视野，按现场开放动线走。
3. **15:20—17:00 品清湖滨水线**：天气舒服就沿湖散步；暴雨、高温或风大时换非遗展示馆 / 天后阁。
4. **17:30—20:30 五马路 + 二马路**：先用五马路本地小吃填肚，再去二马路小份尝味、夜逛。人多时不排爆红店。

## D2｜红海湾拍照线

1. **上午尽早进入红海湾片区**：景点分散，优先解决当天租车或确认网约车；不把多个海湾当步行串联。
2. **海上古堡**：先拍外围海岸和建筑关系，核对入口、潮位、风浪和现场管理。
3. **浮日湾 / 风车岛**：拍海湾、建筑、风车与落日氛围；排队或异地还车限制明显时缩短停留。
4. **后澳玻璃海 / 浅水湾触发项**：只有天气、海水能见度、人流和卫生都合适才加入；否则直接收队。
5. **14:30 左右结束远端拍摄**：给 16:00 离开留出回到集合点、取物和叫车余量。

## 替换关系

- 红海湾风浪大、交通难：改走金町湾沙滩、风帆礼堂、鲸湾小镇，保留日落。
- 只想轻松拍海：删掉玻璃海和浅水湾，主线只留海上古堡 + 浮日湾。
- D1 下雨：凤山祖庙短停，品清湖改非遗展示馆 / 天后阁；美食线不变。

## 出发前复核

- 红海湾景点开放、入口和临时管制。
- 天气、风浪、潮汐、台风后海水卫生。
- 小电驴租还点、异地还车规则、网约车回程可得性。
- 五马路 / 二马路门店当天营业、排队、时价和是否休渔期。
