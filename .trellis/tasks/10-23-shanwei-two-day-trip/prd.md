# 汕尾两天一夜小红书旅行攻略采集与行程

## Goal

基于项目既有的小红书可见页面采集方式，整理一份汕尾本地两天一夜路线：D1 中午开始，D2 16:00 左右结束。重点是本地特色美食、适合拍照的海边与城市风景，以及可执行的转场顺序。

## Background

- 只研究到达汕尾后的本地游玩，不记录深圳出发、高铁耗时或跨城交通。
- 不设汕尾站、二马路市区或红海湾住宿为固定起止点；路线只表达景点顺序、吃玩组合、转场提醒与返程余量，用户可从自己的落脚点接入。
- 站点是 React + TypeScript + Vite 静态应用，旅行数据位于 `src/trips/<slug>/trip.ts`，页面组件在旅行目录注册；本轮新增 `/trips/shanwei-two-day-trip/`。
- 当前湖北观星任务仍独立存在，汕尾任务不能覆盖湖北任务文件。

## Requirements

### R1 · 小红书采集

- 使用 Edge/浏览器插件访问小红书可见搜索结果；不读取隐藏应用状态，不调用小红书内部 API，不发布内容、不联系作者。
- 采用轻量本地研究量：8–10 个查询，每词目标约 30 条不同帖子 ID；每个查询组至少实际打开 5 篇详情。数量不足时记录实际缺口，不伪报达标。
- 查询覆盖：汕尾总览/两天一夜、城区美食与小吃、二马路/五马路、红海湾拍照、浮日湾/风车岛、金町湾、避坑与反向经验。
- 保存搜索记录与详情记录，字段至少包括 `query`、`noteId`、`title`、规范 `url`、`collectedAt`、`readDepth`、`placeMentions`、`decision`、`reason`；搜索卡片与详情阅读分开统计。
- 同一查询按 `noteId` 去重，跨查询重复另计；规范 URL 去掉 `xsec_token` 等会话查询参数，不落盘登录凭据或会话令牌。

### R2 · 景点与餐厅证据

- 景点和餐厅进入候选池前，至少有详情正文、图片说明或评论中的可追溯线索；只有搜索卡片的项目标为待核验。
- 记录位置线索、拍照/吃法理由、转场方式、开放或营业限制、排队、人流、天气、潮汐、租车/寄存和价格波动风险。
- 餐厅同时保留正向与反向证据；不把热度、封面、单篇主观评价或 AI 摘要当成事实。
- 官方文旅资料只用于景区存在性和区域关系交叉核验，不能替代小红书实吃/实拍证据。

### R3 · 两天本地顺序

- D1：城区午餐 → 凤山/品清湖与城市拍照线 → 五马路本地小吃或二马路夜逛。
- D2：红海湾游客中心/租车点 → 海上古堡 → 浮日湾/风车岛 → 玻璃海或浅水湾（按天气、人流触发），14:30 左右结束远端拍摄，为 16:00 离开留余量。
- 金町湾作为低强度沙滩/天气不稳时的替换线；博物馆、非遗馆等作为雨天备选。
- 页面显示主线、Plan B 和触发条件，不假设固定住宿或返程站。

### R4 · 页面接入

- 新增 `src/trips/shanwei-two-day-trip/` 数据、页面和样式，注册到 `src/trips/index.ts`，首页可打开。
- 复用现有 `Trip` 数据契约、`TravelMap`、shadcn 源码组件和普通链接；不引入路由库、状态库或新运行时依赖。
- 地图点位使用有来源的区域/景区参考坐标，明确“参考位置不等于精确机位”；景点、替换点和餐厅在页面中分组展示。

## Evidence already collected

- `research/xhs-initial-scan-2026-10-23.md`：首轮总览、两天攻略、美食、红海湾拍照、城区 Citywalk 和反向避坑详情。
- `research/official-crosscheck-2026-10-23.md`：汕尾官方文旅与红海湾官方资料，核验凤山/品清湖、二马路、红海湾、风车岛的区域关系。
- `research/itinerary-draft.md`、`research/base-options.md`：本地景点顺序和落脚基准比较；当前采用不设固定起止点的路线表达。
- 关键结论：五马路更偏本地小吃，二马路更偏游客夜逛；红海湾点位分散，海上古堡与浮日湾优先，玻璃海/浅水湾看天气和人流。

## Acceptance Criteria

- [ ] 8–10 个查询均有搜索记录；每词目标约 30 条，实际数量、同词去重、跨词去重和详情数可复算。
- [ ] 每组至少 5 篇详情或记录真实缺口；主线景点与餐厅均有来源或明确待核验标记。
- [ ] 研究文件包含正反证据、风险与出发前复核项；不保存会话令牌。
- [ ] D1/D2 顺序覆盖中午开始、吃饭、拍照、替换线和 16:00 左右结束；不包含深圳出发段。
- [ ] `/trips/shanwei-two-day-trip/` 可从首页打开，地图、点位分组、逐日计划、餐食与复核清单可读。
- [ ] `npm run lint`、`npm run typecheck`、`npm run build`、`npm audit` 通过；完成桌面和窄屏页面检查。

## Out of scope

- 常驻爬虫、服务端数据库、自动登录、代用户发布/点赞/评论、批量下载图片。
- 深圳出发及返程高铁方案、跨城交通时刻、固定酒店或返程站推荐。
- 代订酒店、车票、餐厅或付款；不承诺实时营业、天气、潮汐、租车和价格。
