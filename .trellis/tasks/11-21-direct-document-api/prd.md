# 本地页面直连线上文档 API

用户已确认方案并要求继续实施。小范围修复，无新依赖。

## 需求
- 开发页面直接请求 https://trip.flands.com/api，移除 Vite /api 转发；线上继续同源请求。
- 读取、密码验证、保存共用现有请求函数；保留 D1、版本校验和密码门禁。
- API 支持 localhost / 127.0.0.1 开发源的 CORS 与 OPTIONS；拒绝其他跨域来源，不放开任意源。
- 12秒超时显示中文；取消请求不误报超时。

## 验收
- 测试涵盖 CORS 预检、允许/拒绝来源、错误响应跨域头、密码保护及同源行为。
- npm run test:tables、npm run check、Functions构建通过。
- 发布后在 Edge 本地页面确认请求直接指向线上、数据加载成功，比较耗时。
- 不修改真实记录，不提交无关北海道文件。

## 已有证据
Vite转发实测超过15秒/3.24秒/6.62秒；浏览器所用系统代理对应的线路1.50秒/0.35秒/0.28秒。Node转发未使用Windows系统代理，触发前端12秒超时。
